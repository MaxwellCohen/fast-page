The second page

You came here from the previous page in the same session, so the browser has already seen this site's CSS. This page links the same stylesheet, which is already in the HTTP cache: zero bytes and zero round trips for CSS. Before a browser can paint anything it needs every render-blocking stylesheet in the head. With a link tag that means: download the HTML, parse it, find the link, then make a second request and wait for it. With a style tag the CSS is already in the HTML response, so the first paint can happen as soon as the head has arrived. The difference is roughly one network round trip, plus the time to download the stylesheet bytes. On a fast, nearby connection that is a few milliseconds. On a mobile connection with 150 ms of latency it is often the single biggest item on the critical path.
